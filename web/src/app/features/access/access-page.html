Users and access

Overrides for one user

How overrides work

effective = (role grants ∪ group-role grants ∪ allow overrides) − deny overrides − switched-off modules

  • Deny wins. An unexpired deny removes a permission even if a role or an allow grants it.
  • Until makes it temporary. For a vendor, contractor or auditor who needs access for days: grant it with a reason and an expiry instead of creating a new role. After Until it stops counting.
  • Every override is audited with its reason, and replacing one checks its version first.
Source: ADR-008, auth and identity model
