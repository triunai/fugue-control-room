  **Fix:** Force a version-guarded update for existing overrides, including no-op submissions. Add a regression test that races a change against an identical PUT.

Many IPs can simultaneously pass the check and perform arbitrarily more than 50 guesses; subsequent failed charges are ignored. The concurrency limit applies only within each `(IP, email)` bucket.  
  **Fix:** Atomically reserve email capacity before verification, counting in-flight attempts, and refund successful attempts. Add a concurrent test across distinct IPs.
